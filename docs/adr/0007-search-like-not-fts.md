# 搜索只对书名和作者做 LIKE，不用全文索引

搜索只对书名、作者、丛书名做 `LIKE '%词%'`。2 万本书时实测约 4–5 ms（`research/ScalePerf.md:24`），1–2 个汉字的查询也能查到。

## 考虑过的方案

- FTS5 `trigram`：1–2 个汉字的查询直接返回 0 条，而中文短查询很常见。
- 应用层 bigram 分词加首字索引：召回率最好，但要自己写分词，还要维护索引同步。
- Meilisearch 等外部搜索服务：多一个要运维的进程。

## 后果

- 不支持搜简介和正文：对 1 KiB 简介做 `LIKE` 要 170–210 ms。
- 出现以下任一情况时，换成 bigram FTS5：需要搜简介；书库超过 10 万本。
