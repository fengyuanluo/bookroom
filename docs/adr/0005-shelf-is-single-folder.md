# 书单是单归属的嵌套文件夹，兼作分类

首屏的书单直接对应 Readest 的文件夹（书记录上的 `groupId`/`groupName`，用 `/` 表示嵌套，见 `GroupingModal.tsx:97`）。一本书最多属于一个书单，书单同时承担分类的职责；书单之外的维度用标签表示，"未读/在读/读完/弃读"用 Readest 自带的阅读状态。文件夹字段已经由 Readest 同步（字段级时钟 `groupUpdatedAt`），所以客户端数据层不用改。

## 考虑过的方案

- legado 式多归属分组（`Book.group` 是位掩码）：一本书可以同时放进多个分组，但需要扩展 Readest 的同步模型和文件夹 UI，而且"书单"和"分类"会变成两个概念。

## 后果

- 想让一本书同时出现在两个书单里做不到，这种需求改用标签。
- 书单属于用户：多用户时每个用户的文件夹结构互不影响，书库本身是共享的。
